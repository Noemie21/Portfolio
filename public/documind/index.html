RAG System

🧠 DocuMind

Upload PDF, Word or text files and ask questions about them. Every answer cites the document and page it comes from.

Open full screen ↗ Source code on GitHub
  • RAG with LangChain
  • ChromaDB
  • GPT-4o-mini
  • Streaming answers
  • Conversation memory
  • Source citations

To try it: upload a PDF, Word or text file in the sidebar, then ask a question in the chat. Your documents stay private to your session. If the demo has been idle, it can take about 30 seconds to wake up.

01Index

Documents are split into chunks and embedded into a private, per-session vector store.

02Retrieve

Follow-up questions are rewritten using the conversation, then the most relevant chunks are found.

03Answer

The model answers only from those chunks, streams the reply and shows its sources.
